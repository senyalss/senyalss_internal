# ⚡ senyalss internal

> **by senyalss & gemini** — премиальный, ультра-минималистичный софт для кастомизации и ремапа компактных клавиатур (идеально для Defender Black Raven GK-417 и других 60% плат), выполненный в строгом геймерском Midnight-дизайне с динамическими RGB-эффектами.

## 🔥 Ключевые фичи софта

* 💎 **Midnight Style:** Глубокий матовый черный интерфейс в стиле топового приватного игрового софта (Midnight, Neverlose). Никакого визуального мусора.
* 🌈 **Dynamic RGB:** Аккуратное, плавное переливание верхней навигационной панели и системных элементов, реагирующее в реальном времени.
* ⌨️ **Core Remap Engine:** Глобальный низкоуровневый перехват и переназначение любых клавиш (мега-полезно для 60% плат, чтобы переносить Caps Lock, FN, стрелки или делать макросы).
* 💾 **JSON Configuration:** Автоматическое сохранение всех добавленных биндов «на лету» в файл `config.json` в корне программы. При перезапуске конфиг подтягивается сам.
* 🧠 **Gemini Collab:** Специальный интерактивный лог инициализации ядра, разработанный совместно с нейросетью.

## 🛠️ Как запустить из исходников (Для разработчиков)

### 1. Системные требования
* **ОС:** Windows 10 / 11
* **Язык:** Python 3.10+
* **Зависимости:** `PyQt6`, `keyboard`

### 2. Установка библиотек
Откройте терминал в папке проекта (PyCharm Terminal) и установите зависимости:
```bash
pip install PyQt6 keyboard
```

### 3. Запуск
> ⚠️ **КРИТИЧЕСКИ ВАЖНО:** Поскольку библиотека `keyboard` делает низкоуровневый перехват глобальных хуков клавиш в Windows, среду разработки (PyCharm) или сам скрипт **ОБЯЗАТЕЛЬНО нужно запускать от имени Администратора**, иначе Windows заблокирует работу ремапа.

```bash
python main.py
```

## 📦 Как собрать готовый самостоятельный `.exe` файл

Если вы хотите упаковать проект в один исполняемый файл с красивой иконкой (чтобы запускать без установленного Python), используйте `PyInstaller`:

1. Установите сборщик: `pip install pyinstaller`
2. Сконвертируйте созданный `logo.png` в формат `icon.ico` (через любой онлайн-конвертер) и положите в папку проекта.
3. Запустите финальную сборку в терминале:
```bash
pyinstaller --onefile --noconsole --clean --icon=icon.ico main.py
```
Забирайте готовое приложение из появившейся папки `dist`!

## 🤝 Hardware Моддинг (Бонус от авторов)
Проект создавался в процессе кастомизации механики **Defender Black Raven**. Рекомендуемый физический моддинг платы под этот софт:
1. **Утяжеление:** Заливка ячеек корпуса термоклеем с гайками или автомобильными грузиками (металл обязательно изолировать малярным скотчем сверху!).
2. **Подсветка:** Полная перепайка старой радужной подсветки на прямоугольные белые светодиоды формата `2x3x4 мм` (длинная нога диода — это ПЛЮС) с использованием флюса `ЛТИ-120` и припоя `ПОС-63`.
